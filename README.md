## 🤖 Makine Öğrenmesi Final Projesi

Final proje kapsamında, telefonların teknik özelliklerinden yararlanarak
fiyat sınıflarını tahmin eden bir makine öğrenmesi modeli geliştirdim.

Projede:

- Veri setinin incelenmesi
- Veri görselleştirme
- Eğitim ve test verilerinin ayrılması
- Random Forest sınıflandırma modeli
- Accuracy ve Confusion Matrix ile model değerlendirme
- Feature Importance analizi

adımlarını uyguladım.

Model, test verileri üzerinde yaklaşık **%88 doğruluk** elde etti.
